# 🚀 Md Maruf Hasan | Frontend Developer Portfolio

A modern, high-performance, editorial brutalist portfolio website showcasing featured web development projects, technical skills, and educational background. Built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## ✨ Key Features

- **Editorial Brutalist Design**: Striking dark-mode aesthetic with custom typography (`Anton` + `Roboto`), minimal grid borders, and neon green (`#00FF41`) accents.
- **Ultra-Smooth Scrolling**: Powered by [Lenis](https://github.com/darkroomengineering/lenis) with custom spring physics and top reading progress indicator.
- **Interactive Particle Starfield**: Canvas-based ambient dust particle field reacting subtly to user motion.
- **Dynamic Projects Showcase**: Interactive desktop split preview with hover state transitions and responsive mobile cards.
- **Categorized Tech Stack**: Clean categorized layout highlighting frontend, backend, and development tools with branded icons.
- **Education & Credentials**: Dedicated academic and professional certifications showcase.
- **Fully Responsive**: Optimized for seamless viewing across ultra-wide monitors, laptops, tablets, and smartphones.

## 💻 Getting Started Locally

### Prerequisites
Make sure you have Node.js (v18.17 or higher) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/0MarufHasan0/protfolio-maruf.git
   cd protfolio-maruf
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the live site.

### Build for Production
```bash
npm run build
npm run start
```
